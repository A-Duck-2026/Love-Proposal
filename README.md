# Love Proposal

A cute, interactive Flutter app designed as a romantic proposal experience.  
It features a runaway **"Not at all"** button, floating hearts animation, a teddy-bear sticker, and Firebase Firestore to store the response when the user says **Yes**.

---

## ✨ Features

- Beautiful soft pink gradient UI
- Floating animated hearts background
- Teddy bear love sticker
- **"Yes, of course!"** button
- Runaway **"Not at all"** button (moves randomly up to 12 times)
- After 12 attempts the app gently forces the user to choose Yes
- Submit answer to **Firebase Firestore**
- Success / playful dialogs
- Fully responsive design
